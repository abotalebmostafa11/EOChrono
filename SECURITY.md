# Security

Do not publish Copernicus Data Space credentials, access tokens, passwords or private service URLs in issues, commits, logs or example files.

If a credential has been committed accidentally:

1. Revoke or rotate it immediately.
2. Remove it from the public repository history where appropriate.
3. Create a replacement credential.
4. Check logs for unauthorized use.
